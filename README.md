# Kanji Crawl

A free browser roguelite for Japanese learners: every attack is a kanji. Fight yokai, pick relics, and face bosses built from the kanji you keep missing. JLPT N5 (79 kanji).

Play: open `index.html` (also served by GitHub Pages).
